# CareDesk AI - Backend / Frontend

## 1. 프로젝트 개요

CareDesk AI는 기업과 소상공인의 반복적인 고객 문의를 AI가 대신 처리해주는 **AI CS Managed Service MVP**입니다.

이 저장소의 `backend`와 `frontend` 영역은 고객사 관리, FAQ/정책 문서 관리, AI 응답 요청, 상담 로그 저장, 사용량 집계, 관리자 화면을 담당합니다.

단순 챗봇이 아니라, 고객사의 CS 업무를 줄여주는 운영형 서비스를 목표로 합니다.

---

## 2. MVP 목표

1차 MVP의 목표는 다음 흐름을 구현하는 것입니다.

```text
고객사 등록
→ FAQ/정책 문서 등록
→ 고객 질문 입력
→ AI 서버에 답변 요청
→ AI 응답 결과 수신
→ 상담 로그 저장
→ 사람 이관 여부 저장
→ 사용량 집계
→ 관리자 화면에서 확인
